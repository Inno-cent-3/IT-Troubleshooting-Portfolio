# IT Troubleshooting Portfolio

This repository contains real-world troubleshooting cases, homelab projects, and technical incidents that I have investigated and resolved while developing my IT support, networking, and system administration skills.

## Cases

### Case 001 - Windows PC Connected to Wi‑Fi but Unable to Access the Internet

**Problem:** Desktop connected to Wi‑Fi, obtained a valid DHCP address, but could not access network resources.

**Skills Demonstrated:**
- DHCP Troubleshooting
- ARP Analysis
- Route Verification
- Wi‑Fi Troubleshooting
- Windows Networking
- Problem Isolation
- Documentation

**Resolution:** Assigned a new locally administered MAC address to the wireless adapter after ruling out DHCP, routing, firewall, and adapter-related causes.
